# Build Porch: Champaign–Urbana apartment research website

## Goal

Create a polished, mobile-friendly apartment directory scoped to a fast prototype.

## Acceptance criteria

- [x] Curated real communities with official source links and explicit unknown availability.
- [x] Search, budget, bedroom and amenity filters, sorting, saved apartments, comparison, and details.
- [x] Layout-aware pricing; distinguish whole-unit student rates and unknown private rates.
- [x] Clearly label illustrative imagery and university eligibility restrictions.
- [x] Editable Figma desktop and mobile concepts.
- [x] House entrance and door-opening animation, skip control, and reduced-motion support.
- [x] Smooth apartment detail transitions and keyboard-accessible dismissal.
- [x] Automated pricing/filter tests and local desktop browser checks.
- [ ] Verify the layout on a physical mobile device.
- [ ] Confirm production photo reuse permissions and refresh listing data before broader launch.
